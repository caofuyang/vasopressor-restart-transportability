# Clinical results enhancement rules (frozen before calculation)

Date frozen: 2026-09-09 (Asia/Shanghai)

This is a post hoc descriptive and exploratory extension of the frozen post-audit analyses. It does not change the endpoint definitions, cohorts, partitions, predictors, preprocessing, fitted models, or performance estimates.

## Restart-time distribution

- Use only records in each database's corrected primary analysis classified as restart first.
- Use the first confirmed restart time already generated by the corrected endpoint code; do not regenerate or redefine the endpoint.
- Compute elapsed hours from the qualifying cessation origin to the first restart.
- Report nonmissing and missing elapsed times, median, first quartile, third quartile, and counts/proportions in the fixed intervals `(0,1]`, `(1,6]`, `(6,12]`, and `(12,24]` hours.
- Interval proportions use all restart-first records as the denominator; missing times are reported separately. The interval-count sum must equal the number of valid times in `(0,24]` or the discrepancy must be explained.
- The plot is a conditional distribution among recorded restart-first events, not cumulative incidence or risk among all cessation records.
- MIMIC-IV and eICU are displayed separately because cessation and medication-recording rules differ.

## Clinical characteristics by corrected outcome

- Include only corrected primary-analysis records and retain exactly three mutually exclusive outcomes: restart first, death first/administrative death proxy first, and no recorded restart or death under complete observation.
- Do not place excluded or indeterminate records in the no-recorded-event group.
- Use the requested, available, interpretable pre-index variables only: age, MAP, heart rate, duration of qualifying vasopressor exposure, last observed norepinephrine-equivalent dose, number of vasopressors, and existing 1-hour or 6-hour dynamic summaries.
- Describe continuous variables with median [Q1, Q3], observed N, and missing N (%). Do not substitute model-imputed values for observed descriptions.
- Standardized differences compare restart first versus no recorded event and death first versus no recorded event. They are descriptive and not adjusted independent effects.
- Do not select variables, groups, windows, or reported findings according to P values or apparent effect size.

## Existing ablation evidence

- Reuse frozen locked-evaluation predictions and paired bootstrap results; do not refit or retune.
- Verify exact feature lists from the saved analysis code/model specifications before naming an ablation.
- Promote the full source versus harmonized dynamic-vitals comparison to the main results, but attribute differences to the complete feature-set contrast rather than to one variable unless the feature lists establish that only one variable class differs.
- Separate probability calibration/error from discrimination. Do not infer a causal mechanism for transport failure.

## Reporting boundaries

- New analyses are post hoc descriptive/exploratory.
- No safety window, causal effect, independent risk factor, or clinical decision threshold will be claimed.
- Patient-level data and predictions remain restricted and will not be exported in the submission package.
